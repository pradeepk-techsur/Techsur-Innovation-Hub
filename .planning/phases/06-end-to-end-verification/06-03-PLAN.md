Apply every fix identified in the triage report. Each fix follows the pattern:
1. Read the triage entry (bug/gap/design-decision)

3. Re-run ONLY that requirement's test to verify it now passes
4. Commit the fix with [REQ-ID] in the commit message
5. Record the fix in FIX-LOG.md
6. Move to the next triage item

After all fixes: re-run the full requirement suite to confirm zero regressions.

This plan is driven entirely by docs/TRIAGE-REPORT.md from plan 06-02.
The exact files modified depend on what failures were found — this plan cannot specify them in advance.

  <name>Task 1: Process triage report and apply all fixes</name>
  <files>
    docs/FIX-LOG.md

  <action>
**Read docs/TRIAGE-REPORT.md** and process each entry in order:

---

**For each Bug entry:**

1. Read the REQ-ID, requirement text, root cause, and proposed fix from the triage report.
2. Locate the relevant source file(s).
3. Apply the targeted fix — minimal change to make the test pass without breaking other behavior.
4. Re-run the specific test:
   ```bash
   npx playwright test e2e/requirements/ --grep "\[{REQ-ID}\]" --reporter=list
   ```
5. If test passes: commit with message `fix({req-id}): {brief description}`
6. If test still fails: investigate further, fix again, repeat until green.
7. Record in FIX-LOG.md:
   ```
   | {REQ-ID} | Bug fix | {files changed} | Re-ran test → PASS | ✓ |
   ```

---

**For each Gap entry:**

1. Implement the missing feature or behavior.
2. Re-run the specific test and verify it passes.
3. Commit with message `feat({req-id}): {brief description}`
4. Record in FIX-LOG.md.

---

**For each Design Decision entry:**

1. Update the requirement text in `.planning/REQUIREMENTS.md` to accurately describe actual behavior.
2. Update the test in `e2e/requirements/*.req.spec.ts` to match the actual (correct) behavior.
3. Re-run the test to confirm it passes with the updated assertion.
4. Commit with message `docs({req-id}): align requirement and test with design decision`
5. Record in FIX-LOG.md:
   ```
   | {REQ-ID} | Design decision | REQUIREMENTS.md + test | Test updated → PASS | ✓ |
   ```

---

**After all individual fixes:**

Run the full suite to check for regressions:
```bash
npx playwright test e2e/requirements/ --reporter=list 2>&1 | tail -20
```

If any NEW failures appear (regressions from fixes), treat them as additional Bugs and fix before proceeding.

**Build check after all fixes:**
```bash
npx next build 2>&1 | tail -10
```

Build must pass (`build_exit=0`) before plan 06-03 is considered complete.
